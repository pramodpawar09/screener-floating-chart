How it works / configuration

Prices are real historical candles (not a live feed) fetched through the extension's background worker. No API key is needed for the default provider. To use a different provider, implement the provider interface in src/services/providers/ and select it in src/background/service-worker.js.

Tips: hover a stock name to preview. Use the pin button, or Alt+click a name, to keep it open. Esc closes.
